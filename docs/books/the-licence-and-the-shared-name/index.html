The Licence and the Shared Name

How to Give an Idea Away Without Letting It Be Captured

Follow software’s journey from copyable tool to industrial commons, then confront the asset its licences rarely distribute: trusted identity. The book invites builders, maintainers, companies, and policymakers to imagine open ecosystems in which reputation carries reciprocal obligations without restricting everyone’s freedom to use the code.
